# AquariumTV – a Roku screensaver

A reef tank screensaver for Roku (SceneGraph, 1080p). The background and fish are generated with the
local Stable Diffusion WebUI. Light rays and bubbles are drawn by script.

```
roku/        the channel (manifest, BrightScript, images/ built by tools/process.py)
tools/       asset pipeline (generate → pick → process → package)
dist/        built zip
```

## Asset pipeline

Run everything with the tools venv: `tools\.venv\Scripts\python.exe`.

1. Start the WebUI with `--api` (add it to `COMMANDLINE_ARGS` in `webui-user.bat`).
2. `python tools/generate.py` creates candidates in `tools/raw/` using the prompts and fish list in
   `tools/assets.json`. Existing files are skipped; use `--force`, `-n 6` or name targets
   (`background`, `clownfish`, …) to redo specific assets.
3. `python tools/process.py --sheets` writes contact sheets to `tools/raw/sheets/`, showing each candidate
   and its cutout (rembg / BiRefNet).
4. Pick candidates in `tools/selection.json`. Set `facing` to the direction the fish faces in the raw
   image, and the script mirrors it as needed.
5. `python tools/process.py` builds `roku/images/`.

Optional: `python tools/upscale.py bg_01 --model epicphotogasm_ultimateFidelity.safetensors --sampler "DPM++ 2M" --cfg 5 --steps 30 --tile 768 --overlap 192 --out bg_01_4k_epic`
upscales a background to 4032×2304 (R-ESRGAN 2×, then a tiled SD img2img detail pass). The original is left untouched.
The shipped background, `bg_01_4k_epic`, was made this way. Its 2016×1152 source has since been deleted, so a new upscale needs a newly generated background.

Unused candidates were cleaned out of `tools/raw/`, so only the selected image for each asset remains.
`generate.py` skips numbers that already exist, so new candidates for an asset need `--start` to pick a free number.

To add a species, add an entry to `assets.json` (`size` is its on-screen width in px at 1080p;
`kind` is `solo` or `school`), then generate, pick and process it. No code changes are needed.

## Store artwork

**Poster and icons come from one file: `art/poster.png`.** Edit it to add a title or change the artwork. It should be 4:3,
ideally 1080×810 or larger. Other sizes are centre-cropped, and transparency is flattened, because Roku artwork must be opaque.
The scripts never overwrite it. If it's missing, it's seeded with a text-free render of the reef. These are generated from it:
- `roku/images/icon_fhd.jpg` (540×405) and `icon_hd.jpg` (290×218), regenerated by `process.py`
- `store/poster_540x405.png`, regenerated by `render_preview.py`

After editing it, run `process.py`, `render_preview.py` and `package.py`.

The splash screen is a rendered frame of the scene (see `tools/render_preview.py`). For a store listing,
`python tools/render_preview.py` writes `store/`:
- the poster (from `art/poster.png`)
- five screenshots (1920×1080), covering the full reef, the crab, the shark and the chromis schools

These match Roku's publishing requirements: one 540×405 poster and up to six 1920×1080 screenshots.
To change a shot, edit `SHOTS` in that script, which sets fish positions, depths and drift for each frame.

## Installing on a Roku

1. Enable developer mode on the Roku: Home ×3, Up ×2, Right, Left, Right, Left, Right. Set a password.
2. `python tools/package.py` increments `build_version` and builds `dist/aquariumtv.zip`. Upload it at `http://<roku-ip>`
   (user `rokudev`), or deploy it directly:
   ```
   set ROKU_IP=192.168.1.50
   set ROKU_PASS=yourdevpassword
   python tools/package.py --deploy
   ```
3. Go to **Settings → Theme → Screensavers**, choose **AquariumTV**, and use **Preview** to watch it right away.
   It's a standalone screensaver, so it has no home-screen launch. Roku prohibits `Main()` in screensavers.

## Roku certification notes

Checked against Roku's docs in November 2026:
- Entry point: `RunScreenSaver()` only. `Main()` and `RunUserInterface()` are prohibited.
- Manifest: `screensaver_title` instead of `title`. Static analysis treats a `title=` as a regular channel.
  `rsg_version=1.3`, required since 1 Oct 2026. FHD/HD icons, plus FHD/HD/SD splash screens.
- `roAppMemoryMonitor` memory warnings are enabled in `main.brs`. Required since 1 Oct 2026.
- `AppLaunchComplete` beacon is fired once the scene is built.
- No input handling, deep linking, audio/video, ads, network or component libraries.
- Package under 4 MB. `process.py` saves sprites as palette PNGs via libimagequant.
- `package.py` increments `build_version` on every release build, because Roku only accepts updates with a higher version. Debug builds leave it alone. Change `major_version`/`minor_version` by hand for bigger releases.

The current Roku docs don't say whether screensavers need the `AppLaunchComplete` beacon, and developers report that
it logs "not reachable" from `RunScreenSaver()`. It's included because it's harmless.

Static analysis runs when you upload in the Developer Dashboard. That's the final check for these points.

Tools setup: `python -m venv tools\.venv` and `tools\.venv\Scripts\pip install -r tools\requirements.txt`.

Diagnostics: `python tools/package.py --debug` builds `dist/aquariumtv_debug.zip`. It draws a red frame on the edges of the
1920×1080 canvas and shows the resolution the Roku renders at. It's turned on by `bs_const=DEBUG_OVERLAY` only inside that zip,
so it's compiled out of the release build.
